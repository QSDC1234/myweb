# 直列四缸四冲程汽油发动机 · 交互式工程模型

一个**零外部依赖**（无 Three.js，纯手写 WebGL）的浏览器端交互式 3D 发动机模型，用于学习四冲程内燃机工作原理、观察内部机械结构与动态演示。

## 运行方式（本地预览）

```bash
cd "D:\ai work\engine3d"
node server.js
```

然后打开浏览器访问：**http://localhost:8090**

（也可用任意静态文件服务器托管 `public/` 目录；ES Module 需要 HTTP 服务，不能直接用 `file://` 打开。）

## 部署

本项目为**纯静态、零后端、零构建**：只需把 `public/` 目录上传到任意静态托管平台即可公网访问。详见 [DEPLOY.md](DEPLOY.md)（含 Netlify / Vercel / GitHub Pages / Cloudflare Pages / 对象存储 等具体步骤）。

## 工程正确性（已用 Node 单元测试验证）

- **曲柄连杆机构**：精确滑块-曲柄公式 `y = r·cosθ + √(L² − r²·sin²θ)`，r=43mm，L=146mm，曲轴曲柄销相位 `0°-180°-180°-0°`。
- **配气相位**：凸轮轴转速 = 曲轴 1/2（链轮齿数比 2:1）；进气门开 350°、闭 590°，排气门开 130°、闭 370°（以点火上止点 0° 计），升程 8mm；凸轮轮廓与气门升程由同一函数生成，几何与运动严格一致。
- **点火顺序 1-3-4-2**：点火相位 [0°, 540°, 180°, 360°]，四个气缸互差 180°，冲程映射（做功→排气→进气→压缩）正确。

## 功能

- **双发动机切换**：顶部「直列四缸 / V8」按钮即时切换（无刷新、平滑淡入淡出），两套模型独立存在，各自保存 RPM / 曲轴转角 / 拆解状态
  - **直列四缸**：四冲程，点火顺序 1-3-4-2
  - **V8**：90° V 型、十字平面曲轴、8 缸 16 气门、两排气缸盖，点火顺序 1-8-4-3-6-5-7-2，每缸相位按曲轴精确计算
- 旋转 / 缩放 / 平移 / 触控（自实现轨道相机）
- 点击零件选择 + 高亮 + 名称/功能/机械关系/**运动方式**说明
- 结构树（按系统分组，可展开子零件）、显示/隐藏、单独显示（隔离）
- **动态逐层分离（Exploded View）**：8 个结构层级，分离程度滑块平滑插值，逐层拆解 / 上一步 / 恢复完整按钮，自动聚焦当前层，可切换"位置连线"（半透明引导线）
- **拆解后机械运动不中断**：爆炸偏移与机械动画坐标系分离，100% 拆解时曲轴仍旋转、活塞仍往复、连杆仍摆动、凸轮轴仍以 1/2 转速旋转、气门仍按凸轮开闭
- 剖切模式（剖切位置滑块 + 翻转方向）、透视模式（壳体半透明）
- 转速滑块 0–6000 RPM + 预设档位、播放 / 暂停 / 单步
- 工作循环演示（四缸/八缸实时冲程状态 + 彩色缸内工质 + 点火火焰）
- 响应式布局（电脑三栏 / 手机上下排列）

## 模型说明（简化声明）

配气机构采用 **SOHC 单凸轮轴 + 摇臂，每缸 2 气门（1 进 1 排），气门沿曲轴轴线布置在气缸中心线上**——目的是让**单一纵向剖切面**同时展示凸轮、摇臂、气门、活塞与曲轴。真实现代发动机多为每缸 4 气门（2 进 2 排）DOHC 横向布置，配气原理与本模型一致。进/排气道、水套与油道的内部铸造形状为示意性简化（半透明管路表示流向）。
